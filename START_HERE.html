Engineering Efficiency Ltd - CAFM Asset + PPM Importer v8.0

Default safety mode: iteration is OFF, therefore one complete Asset + linked PPM cycle runs and stops.

Install

  1. Open chrome://extensions.
  2. Remove/disable the older importer.
  3. Enable Developer mode.
  4. Choose Load unpacked and select this v8.0 folder.
  5. Reload Concept Evolution with Ctrl+F5.

Run

  1. Open Asset - New Entity.
  2. Load the XLSX workbook.
  3. For one asset, leave Enable multiple asset iterations unchecked.
  4. For a batch, enable it and enter the required asset count.
  5. Click Start automatic.

Timing

No fixed delay is applied between records. The extension advances when CAFM state is verified. Safety timeouts stop and report a stalled request.

If something fails

Do not restart from the beginning. Click Download diagnostic JSON and Download CSV log. The diagnostic records the asset, PPM, phase and page state needed to isolate the failure.

PPM

PPM rows are read from Excel by Asset Code. New PPMs are saved and then changed to Active. The extension does not assume a fixed number of PPMs per asset.
